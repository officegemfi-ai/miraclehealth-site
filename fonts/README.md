# Fonts

Words are set in Mona Sans; headlines use the same file at a wider, heavier cut. Numbers, labels and
the code on Ask Sig's screen are set in Monaspace Neon. Both are licensed under the SIL Open Font
License 1.1; the licence text for each sits beside the files. The files are the Latin sets as
published, not re-cut or renamed.
